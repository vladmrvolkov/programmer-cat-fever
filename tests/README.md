# Reading tests

In each test an image was shown to four chat models — ChatGPT, Claude, Gemini and DeepSeek — in fresh chats, and the questions were asked one at a time. Each test page has the image, the questions, the four full answers and a short summary. Tests are added here together with the reports that use them; some are published on their own (no report in the last column), mostly tests on the cat joke whose article is still in preparation. The numbers follow the project's whole series of tests, so there are gaps. Some tests were run with context given on purpose, some are controls with a false hint — their pages say so. The image names under "shown as" are the names the models saw.

**These tests do not compare the models.** The aim was a spread of answers from four readers, not a ranking.
