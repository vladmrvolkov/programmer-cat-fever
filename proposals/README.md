# Directors' proposals

What the virtual directors proposed for the pictures published in this repository, in a plain English translation of conversations held in Russian. A virtual director is a chat model with a system prompt (sometimes a painter persona) that proposes the idea of a picture: the reading, the pictorial source, the key detail; an image generator then draws it. The researcher chooses among the proposals.

Each file covers one subject and says which tests and reports it belongs to. Only the proposals and the directors' comments on them are translated; image prompts, generation reports and edits are left out, except where the files say otherwise. Each file opens with a note on what is translated and how. The translations were made by Claude (Opus 5.5) and are not literary; the Russian originals are not published. Proposals that the researcher made in the same conversations through a working Claude chat, not a director, are not here: the manga of tests 38–50, the harsh version and the diptych of test 21, and the context pictures of tests 45–46.
